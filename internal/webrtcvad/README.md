# WebRTC VAD source

This package vendors the `libfvad` source from
<https://github.com/dpirch/libfvad> at commit
`532ab666c20d3cfda38bca63abbb0f152706c369`.

The upstream source is compiled directly into the Go package. No system
library or runtime DLL is required. Upstream's BSD license, patent grant, and
author list are preserved under `upstream/`.
