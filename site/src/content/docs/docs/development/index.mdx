This section is for contributors and maintainers. If you want to install,
configure, or use Freehand, start with the [user guide](../getting-started/).

## Start contributing

<Steps>

1. **Set up the repository.** Follow the
   [contribution guide](https://github.com/tnware/freehand-stt/blob/main/CONTRIBUTING.md)
   for prerequisites, local builds, and pull-request expectations.
2. **Choose the procedure for your change.** Use the guides below for generated
   assets, compatibility, storage, CI, or releases.
3. **Validate at the right boundary.** Run the required checks and relevant
   [native acceptance](../safety/native-test-checklist/) on each affected OS and
   architecture. Record evidence and remaining gaps in the issue or pull request.

</Steps>

:::caution[Builds and fixtures are separate evidence]
Cross-compilation and browser fixtures do not establish native Windows or macOS
behavior. Live inference checks use only an explicitly selected endpoint/model.
:::
