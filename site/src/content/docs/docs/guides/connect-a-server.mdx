Freehand connects to speech services you provide. It does not install or run a
model itself.

## Choose a topology

All capabilities may share one gateway, or each may use a different server.
They remain independently configurable either way.

### One gateway

```text
Freehand
  ├─ STT ───────────────┐
  ├─ transcript cleanup ├─ https://speech.example.com/v1
  └─ TTS ───────────────┘
```

Use this when one compatible gateway exposes every route and model you need.
Freehand still saves and tests each capability separately because support for
one route does not imply support for the others.

### Separate services

```text
Freehand
  ├─ STT ──────────────── Speaches or another compatible speech server
  ├─ transcript cleanup ─ llama.cpp or another compatible chat server
  └─ TTS ──────────────── Speaches or another compatible speech server
```

Use this when models live on different machines or runtimes. A cleanup outage
does not invalidate successful STT: Freehand preserves and delivers the raw
transcript.

Compare operations and evidence in the [backend directory](../../../backends/),
or browse the [backend guides](../../backends/).

## Choose a compatibility profile

Each connection has its own **Compatibility profile** in Settings:

| Connection | Available profiles |
| --- | --- |
| Speech to text (microphone and files) | Generic OpenAI-compatible, Speaches |
| Post-processing | Generic OpenAI-compatible, llama.cpp |
| Speech playback | Generic OpenAI-compatible, Speaches |

**Generic OpenAI-compatible** is the default and preserves existing behavior.
Choose **Speaches** for your Speaches transcription or speech endpoint, or
**llama.cpp** for its text post-processing endpoint. Selecting a profile does
not change the URL, authentication, model, or prompt preset. S1-mini remains
a separate post-processing prompt choice and also works with the Generic
compatibility profile when the endpoint meets that contract.

The selector explains each profile's current scope. Support can depend on the
server version and selected model; a model listing or successful connection
test does not establish inference capabilities. Optional transcription controls
are described below; voice instructions and other unimplemented features remain
unavailable.

**Planned profiles** are visible but disabled, with a description of the work
still needed. A server listed there may already work through Generic; disabled
means its dedicated profile is not implemented. The list is scoped to the
connection's operation. OpenAI hosted is a planned dedicated profile, separate
from the generic protocol baseline.

Save settings to apply a selection. A running job keeps the settings and
credentials it captured when it started. Older configuration files default to
Generic. These settings describe the current connections; named, selectable
saved connections are not available yet.

## Information Freehand needs

For speech to text, collect:

- the base URL including its API prefix, normally `/v1`;
- the exact transcription model ID expected by the server;
- the authentication mode and API key, if required;
- any non-secret gateway headers;
- whether the endpoint is intentionally using plaintext HTTP.

For example:

```text title="Example gateway settings"
Base URL: https://speech.example.com/v1
Model: speech/stt
Authentication: API key (only if required)
```

Freehand appends `/audio/transcriptions`. Do not enter the complete operation
URL unless the server's base path is itself unusual.

## Example: Speaches on your PC

This CPU example uses Docker Desktop with Linux containers on Windows 11. It
needs disk space for the container and one English speech model, plus internet
access for their initial downloads. Docker and model storage are separate
from Freehand's installer.

:::note[Recipe validation]
Speaches is a validated Freehand backend. This specific CPU recipe follows
upstream instructions and still needs end-to-end Windows validation with the alpha.
:::

<Steps>

1. **Start the speech server.** In PowerShell, run:

   ```powershell title="Start a CPU speech server"
   docker run --detach --name freehand-speaches `
     --publish 127.0.0.1:8000:8000 `
     --volume freehand-speech-models:/home/ubuntu/.cache/huggingface/hub `
     ghcr.io/speaches-ai/speaches:latest-cpu
   ```

   The server is reachable only from this PC. Wait for it to start.

2. **Download one English speech model.**

   ```powershell title="Download the selected speech model"
   Invoke-WebRequest -Method Post `
     -Uri "http://127.0.0.1:8000/v1/models/Systran/faster-distil-whisper-small.en"
   ```

   Wait for the download to finish. This is an explicit server-side download,
   separate from Freehand's metadata-only connection check.

3. **Connect Freehand.** Enter these values under **Settings → Transcription**:

   ```text title="Settings → Transcription"
   Base URL:            http://127.0.0.1:8000/v1
   Model:               Systran/faster-distil-whisper-small.en
   Authentication:      None
   Allow insecure HTTP: On
   ```

   Choose **Save changes**, run **Test connection**, and finish the
   [remaining setup steps](../../getting-started/#first-launch).

4. **Try a short dictation.** Leave **Cleanup** off. Focus Notepad, press
   <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Space</kbd>, say “The release notes
   are ready for review,” and press the shortcut again.

   Expect the speech model's transcript in the same text field after
   processing; punctuation can vary. The first request can take longer while
   the server loads the model.

</Steps>

<details>
<summary>Check, stop, or restart the example server</summary>

If the model is missing from discovery, confirm that its download completed.
If the endpoint is unreachable, inspect the server log:

```powershell title="Inspect the server"
docker logs freehand-speaches
```

Stop the server when you are finished. Restart the same container later to
reuse its model cache:

```powershell title="Stop the server"
docker stop freehand-speaches
```

```powershell title="Restart it later"
docker start freehand-speaches
```

</details>

The `latest-cpu` image tag changes over time; record its digest when reporting
compatibility. See upstream [installation](https://speaches.ai/installation/)
and [model download API](https://github.com/speaches-ai/speaches/blob/v0.8.2/src/speaches/routers/models.py)
for the source of this example.

For a LAN or hosted deployment, obtain its URL, model ID, authentication, and
transport settings from the operator instead of using the localhost values.

## Local and LAN servers

`http://127.0.0.1:8000/v1` and a private address such as
`http://192.168.1.50:8000/v1` are plaintext connections. Freehand rejects them
until **Allow insecure HTTP** is explicitly enabled for that capability.

Only enable plaintext HTTP on a network you trust. Audio, transcript text, and
credentials sent over HTTP are not encrypted in transit. Prefer HTTPS for a
server reached across machines whenever practical.

## Test without invoking a model

Freehand checks a configured health path or `GET /v1/models`. It reports:

- whether the server was reachable;
- HTTP status and request latency;
- a stable failure category;
- discovered model IDs when the response has a compatible model-list shape;
- whether the currently configured model appears in that list.

The check never sends audio or a prompt. **Model list received** means the
server returned a valid model inventory; **Server reachable** means the
configured health endpoint responded successfully. An HTML gateway page or a
malformed model list is an **Invalid response**, even with HTTP status 200.
An empty valid model list is accepted, with the configured model **Not listed**.
Neither check verifies that a model can transcribe or synthesize audio, or that
an endpoint actually enforces the supplied credential.

The optional **Custom health path** is appended beneath the base URL path.
For example, `https://speech.example.com/v1` with `/health` checks
`https://speech.example.com/v1/health`, not the host-root `/health`.
Include the leading slash in the field. Existing saved paths keep this behavior;
a failed custom health check does not trigger a second request to the model list.
Leave the custom path off to use the default model-list check.

First launch requires an explicit **Test connection** before finishing setup.
After setup is complete, Freehand automatically checks the saved STT connection
on launch and after relevant saved connection fields change. A failed check
waits for an explicit retry or a connection-setting change; it does not poll or
iterate through discovered models.

## Transcription controls

Open **Transcription controls** in the speech-to-text Settings section. These
settings apply to microphone recordings, every pause-aware checkpoint, and stored
audio files, including streamed file results. Save before starting a new job.
An active job keeps the settings it captured at its start.

| Setting | Use | Availability |
| --- | --- | --- |
| Transcription context | Short subject matter, names, or examples of expected wording. Sent as `prompt`; blank omits it. | Generic and Speaches; model support varies. |
| Hotwords | Terms to favor during recognition, such as project names. Sent as `hotwords`; blank omits it. | Speaches, qualified against the inspected Whisper paths. |
| Override temperature | Send a value from 0 to 1. Turning it off omits the field and uses the server default. Turning it on with 0 sends an explicit zero. | Generic and Speaches; decoder behavior varies. |

These are recognition hints, separate from the post-processing system instruction.
They do not guarantee spelling or replace words after transcription. Keep context
short: Freehand permits up to 8,192 UTF-8 bytes for context and 2,048 for hotwords,
but a model can have a smaller token budget. Higher temperatures may produce more
variation; leave the override off unless you want to tune the selected model.

Context and hotwords are saved in ordinary local settings and sent with each
transcription request. They are not credentials. Turning the temperature override
off retains its numeric value for later use but does not send it.

Switching from Speaches to Generic with hotwords configured requires clearing
hotwords before saving. The field offers a **Clear hotwords** action; switching
back to Speaches preserves the draft. Freehand never silently sends the
provider-only field through Generic.

Old settings keep every new control unset. **Test** remains metadata-only and
does not send these fields or verify whether a model honors them. For a live
comparison, explicitly transcribe a short sample with your chosen model, change
one option, and compare the result. A server rejection is reported without an
automatic second inference request.
