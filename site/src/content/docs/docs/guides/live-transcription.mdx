Live transcription streams microphone audio to your selected server while you
speak. Review the preview in Freehand or enable overlay captions. By default,
stop recording to finalize the text, run optional cleanup, and deliver it while the original destination is
still safe. Manual-copy mode leaves it ready to copy.

## Choose a model and backend

| Model profile | Qualified backend | Live recognition controls |
| --- | --- | --- |
| [Nemotron 3.5 ASR streaming](../../models/nemotron/) | [NeMo-Speech.cpp v0.1.0](../../backends/nemo-speech/) | Automatic/explicit language; shared vocabulary and strength |
| [Qwen3-ASR](../../models/qwen3-asr/) | [vLLM v0.28.0](../../backends/vllm/) | Automatic language detection |
| [Voxtral Mini Realtime](../../models/voxtral-realtime/) | [vLLM v0.28.0](../../backends/vllm/) | Automatic language detection |

For local setup on Windows or macOS, [install managed NeMo with Nemotron](../local-runtime/).
For a server you manage elsewhere, follow the chosen model's guide. Select its
explicit model profile; a compatible URL or model name alone does not enable live mode.

## Enable live mode

<Steps>

1. **Open Voice transcription → Settings → Transcription** in the right sidebar.
2. **Select the connection, loaded model, and model profile.**
3. **Enable Realtime transcription**, shown for a supported combination.
4. **Optionally enable Live overlay captions.** The main **Overlay** preference
   must also be on.
5. **Choose Save**, then focus the destination and start with your recording shortcut.

</Steps>

Language and vocabulary controls follow the model profile. Unavailable completed
controls remain saved. Edit shared terms under **Settings → Vocabulary** or
Voice's **Vocabulary** options.

## Type completed phrases while recording

This option is **off by default**. In Voice's **Settings → Delivery**, choose
**Direct input** and enable **Type completed phrases while recording**. It requires
NeMo-Speech.cpp with the explicit Nemotron 3.5 streaming profile, Realtime
transcription on, and transcript cleanup off. Save before starting a recording.

Only completed phrases from NeMo are typed. Changing previews are never typed.
Each phrase is checked against the original destination. Keep that destination
focused; if delivery is blocked, review what was already typed before using Copy.
**Cancel cannot remove text that was already typed.**

The choice stays saved when unavailable, with a reason shown beside the disabled
control. With cleanup enabled, text waits until Stop and cleanup completes. vLLM
provides its authoritative final transcript after Stop, so its live previews are
never typed. Your saved choice applies again when the selected mode supports it.

## While recording

| What you do | What happens |
| --- | --- |
| Speak | The preview can change; overlay captions show the newest words |
| Stop or release hold-to-talk | Final text replaces the preview and can proceed to cleanup and delivery |
| Cancel | The preview is discarded; any phrases already typed stay in the destination |
| Lose the stream | Unfinished previews are discarded. With live typing enabled, completed phrases remain available to copy; inspect any text already typed before pasting |
| Turn realtime off for the next run | The same connection/model remain, with saved completed capture preferences |

:::caution[Preview text is not a completed transcript]
Only finalized text can be copied, inserted, cleaned up, or retained in optional
history. Freehand does not replay captured audio after a connection failure.
:::

Live mode uses your toggle/hold shortcut and duration limit. Silence trimming,
checkpoints, and automatic stop are bypassed. Keep the destination focused until
final delivery; [safe insertion rules](../privacy-and-safety/#safe-text-insertion)
still apply.

Audio files keep independent connection, language, and options. When Voice and
files use the same managed runtime they share its selected transcription model;
otherwise their models are independent. File requests remain completed uploads,
even when the server streams text back.
