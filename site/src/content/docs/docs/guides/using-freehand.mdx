import { Steps } from "@astrojs/starlight/components";

Choose a task from the activity rail on the left:

- **Voice transcription** dictates into another application.
- **Audio file** transcribes a recording you select.
- **Text to speech** generates audio from text you enter. You can also listen to
  completed transcripts when text to speech is enabled.

Each task has its own connection and model settings. You can transcribe files or
generate speech without setting up a microphone or recording shortcut.

For initial setup, see [Get started](../../getting-started/).

The rail also opens **Connections**, **Local runtime**, **History**, and **Settings**.
Connections manages saved servers; Settings contains **General**, **Shortcuts**,
**Overlay**, and **Vocabulary**. Use **Local runtime** on the rail
to manage installed runtimes and models. Press
**Ctrl+K** on Windows or **⌘K** on macOS, or select the command bar at the top,
to find a task or settings page. The status bar keeps recording state and the
active task's connection visible as you move between panes.

## Window controls

On Windows, the title bar has **File**, **View**, and **Help** menus beside the
Freehand mark. Minimize, maximize or restore, and close controls sit at the far
right, beside the layout buttons. Drag an empty part of the title bar to move
the window, or double-click it to maximize or restore. On Windows 11, hover over
maximize for Snap Layouts when supported by the installed WebView runtime.

On macOS, use the native traffic lights on the left of the compact title bar
and the system menu bar.
The green control retains macOS fullscreen behavior. Drag an empty part of the
title bar to move the window; double-click follows your macOS title-bar setting.

Closing the workspace asks you to resolve unsaved settings, then hides Freehand.
Choose **Save**, **Discard**, or **Keep editing**. Use the tray or menu-bar icon
to reopen it, and **Quit** from that icon's menu to exit Freehand.

## Check the active connection

Select the connection status at the bottom of the window to see the active
connection and model for the current task. **Check connection** or **Check again**
reads server metadata using your applied settings. It does not record, upload
audio, or run a model. The panel explains failed checks; **Technical details**
expands the individual checks and HTTP status.

Choose **Edit connection** to change the server details or **Choose connection**
to select a server. Checks use the saved connection, not unsaved edits.

## Voice dictation

You need a usable microphone and a configured STT service. A recording shortcut
is optional; it lets you start while another application's text field is focused.
Complete the **Voice** readiness screen before your first recording; see
[Run your first dictation](../../getting-started/#run-your-first-dictation).

Choose a recording style:

|                       | Toggle recording                                              | Hold to talk                                         |
| --------------------- | ------------------------------------------------------------- | ---------------------------------------------------- |
| Start                 | Press the shortcut once                                       | Press and hold the shortcut                          |
| Stop                  | Press it again                                                | Release it                                           |
| Default shortcut      | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Space</kbd>         | Unassigned; configure under **Settings → Shortcuts** |
| Optional silence stop | Available when voice detection and automatic stop are enabled | Waits for shortcut release                           |

<Steps>

1. **Focus the text field** where the transcript should appear.
2. **Start recording** with your toggle or hold-to-talk shortcut. Wait for
   Freehand to show that recording has started, then speak.
3. **Stop recording** with the same shortcut or by releasing the held chord.
4. **Wait for transcription and any enabled cleanup.** Keep the destination
   focused until the result appears.

</Steps>

:::note[When to copy the result]
If you switch applications or windows, Freehand leaves the result available to
copy rather than inserting it elsewhere. On Windows, keep the original text
field focused too; on macOS, you can move between fields in the same window.
Check for partially inserted text before pasting a recovery transcript.
See [Privacy and safety](../privacy-and-safety/#safe-text-insertion) for delivery
restrictions, including macOS Secure Input.
:::

### Toggle recording

Press the toggle shortcut once to begin and again to stop. When local voice detection and automatic stop are both enabled, a toggle recording can also finish after speech has been detected and the configured silence countdown expires.

You can **Clear** the toggle under **Settings → Shortcuts** and save it unassigned.
Use the on-screen recording controls until you assign another chord. Starting
from Freehand does not guarantee delivery into a previously focused application;
review the result and use **Copy** when needed. See
[Keyboard shortcuts](../../reference/shortcuts/) for conflict recovery.

The destination is captured when recording begins. If that destination is no
longer safe when transcription finishes, Freehand leaves the result available
to copy instead of inserting it elsewhere.

### Hold to talk

Press and hold the configured chord, speak, then release it to stop. Automatic
silence ending does not stop a hold-to-talk recording before you release the
shortcut.

A hold-to-talk shortcut can combine modifiers with a key, or use a supported
modifier-only combination. See [Shortcut policy](../../reference/shortcuts/) for
supported combinations.

### Long dictation and VAD

Voice activity detection (VAD) identifies speech and silence on your computer.
It is enabled by default. Open **Voice transcription → Audio** in the right
options sidebar to enable:

- **Trim silence** removes silence at the start and end of a recording.
- **Stop after I finish speaking** ends a toggle recording after a pause.
- **Split long dictation on silence** creates checkpoints to transcribe segments
  while you continue recording. Segments prefer pauses but can split at the
  duration limit.

These three options start off. Checkpoint transcripts are assembled in order
and inserted together when you finish, not pasted while you speak.
For words that appear as you speak, see [Live transcription](../live-transcription/).

## Audio files

Configure the audio-file transcription connection and model, independently of Voice. You do not need a
microphone, recording shortcut, or completed dictation setup.

<Steps>

1. **Open Audio file** and choose **Choose** to select a recording.
2. **Choose the response mode.** Enable **Show text as it arrives** for streaming
   when supported, or leave it off to receive the completed transcript.
3. **Select Transcribe** and wait for the result. Use **Cancel** to stop active work.
4. **Copy the completed transcript** explicitly into the application you want.
   Use **Change** to select another file, or **Again** to transcribe the current file again.

</Steps>

If transcription fails, choose **Details** beside the error for an explanation.
Correct the problem, then choose **Retry** to transcribe the selected file again.

Selecting a file does not upload it until you start transcription. File
results never insert automatically because no destination was captured.

If streaming is rejected or its response is incompatible, the request stops.
Freehand remembers that streaming is unavailable for that endpoint and model;
choose **Retry** to submit a new request in completed mode. This may repeat
server work or incur another charge, so Freehand never resubmits automatically.
A server may also return the complete transcript without text updates.

**Completed transcript** means text updates are unavailable for the current
selection. Use **Try streaming**, when offered, to enable them for the next
request after changing or fixing your server. It does not upload the file until
you start transcription.

If a stream fails, any partial text Freehand received is available to copy, but
is not sent for cleanup. Review it for missing words. Some servers cannot signal
whether a stream is complete; see [file streaming compatibility](../../reference/protocol/).

- Supported formats: FLAC, MP3, MP4, MPEG, MPGA, M4A, OGG, WAV, and WebM.
- Maximum file size: 2 GiB; your server may accept less. Freehand does not split
  oversized files for upload.
- Finish or cancel file transcription before recording with the microphone.

## Current result and task settings

**Current result** holds your latest transcript, including dictation that was
inserted into another application. **Copy** and **Clear** work with history off;
**Listen** is available when text to speech is enabled. A new recording replaces
the dictation result; delayed updates from an earlier attempt cannot replace the
newer dictation. Clear or replace an audio file to remove its result.
You do not need history to copy a transcript after failed insertion.

The task sidebar shows its connection, model, and relevant language, cleanup,
vocabulary, or speech options. Select a row to open the related options beside
your current result. Voice offers **Transcription**, **Audio**, **Cleanup**,
**Vocabulary**, **Overlay**, and **Delivery**. Audio file offers **Transcription**,
**Cleanup**, and **Vocabulary**; Text to speech offers **Speech**.
These edits apply when you save. Direct switches apply immediately. Use the left
sidebar button in the title bar to
reach these controls when the sidebar is hidden.

Shared options identify their scope: Vocabulary and Overlay edit the same saved
preferences available in Settings. Voice's Delivery options contain only microphone
transcript delivery choices; startup and appearance remain in General settings.

### Workspace layout

The title bar has three layout buttons: left sidebar, bottom panel, and right
sidebar. Left-sidebar and bottom-panel visibility apply across the workspace;
right-sidebar options belong to the current page.

Use **Ctrl+B** for the left sidebar, **Ctrl+J** for the bottom panel, and
**Ctrl+Alt+B** for the current task's options or History details. On macOS, use
**⌘** in place of **Ctrl**.

- The **left sidebar** provides quick controls for the current workflow: connection,
  model, language, live dictation, cleanup, or speech voice and speed. These
  changes save immediately. Cleanup is shared by Voice and audio files. A selected
  local connection shows its runtime status and controls directly below the picker,
  including when cleanup is off. Use **Start**, **Stop**, or **Cancel** beside its
  status, and select a downloaded model from the picker below while stopped.
  Progress and errors appear in the same block. **View output** opens that
  runtime in the bottom panel; **Manage runtime** opens its inventory entry.
  Other areas show Settings
  sections, saved connections, runtime inventory, or History. Below 700px wide it starts hidden;
  its title-bar button opens it over the current page.
- The **bottom panel** has **Recent**, **Runtime output**, and **Diagnostics**
  tabs. Its selected tab stays the same when you change pages or hide and restore
  the panel. Global Settings uses the full workspace height and hides this panel;
  returning to another page restores your chosen visibility and tab. It also
  hides automatically in windows shorter than 560px and returns to your chosen
  visibility when there is room.
- The **right sidebar** opens the current workflow's options. In History it offers
  **Details** for the selected transcript and **History settings**. The main
  transcript or composer stays in place while you edit. Use the page's settings
  cog for detailed workflow options such as microphone tuning, model behavior,
  vocabulary, or delivery. These edits use **Save** and **Discard**; quick controls
  pause while you have unsaved changes. Workflow configuration stays closed until
  you open it. Changing pages closes contextual options. Use the **X** in the sidebar's header to close it.
  Below 1100px wide, the sidebar opens as an overlay on the
  right; Escape or the backdrop requests closure. Unsaved edits must be resolved
  before leaving. Widening restores your normal sidebar visibility choice.

Drag either thin divider to resize its region, or focus it with Tab and use the
arrow keys. Home and End move to the permitted size limits. Freehand remembers
layout visibility, sizes, and the bottom tab locally. These preferences do not
store drafts, credentials, transcripts, or runtime output.

In **Runtime output**, select a runtime's tab to display its output immediately.
The first opening selects a running runtime, or the first installed runtime if
none is running. Changing pages keeps your selected runtime. Hiding the panel,
opening global Settings, changing the panel tab or runtime, or hiding the window
clears the viewer and stops its reads. Reopening displays the selected runtime's
available output directly.

Output is read-only and kept in bounded memory. It can include transcripts,
prompts, and file paths; use **Copy selection** only for text you want to share.
Viewing output does not start or stop the runtime. The standalone **Process
output** window requires **Show output** each time it opens or changes runtime.
History remains optional.

Live text follows new words until you scroll back to read earlier text. Choose
**Jump to latest**, or scroll to the bottom, to resume following.

Focus a transcript and use **Ctrl+A** to select its text, then **Ctrl+C** to copy.
Selecting a smaller portion copies only that portion. This also works in expanded
history and each raw/cleaned comparison. **Page Up**, **Page Down**, **Home**, **End**,
and the up/down arrows scroll the containing pane while the transcript has focus.
While text is selected, its displayed text stays still through incoming updates;
clearing the selection shows the latest text. **Jump to latest** clears a result
selection and resumes following. A new recording replaces the previous result.

Edit server addresses and API keys on **Connections** in the activity rail. Choose the
connection and model for each task in that task's settings. Changes do not affect
requests already running.

## Transcript cleanup

For either dictation or audio files, the optional **Cleanup** options can send the
raw transcript to a separate chat service after speech recognition.

- **Raw mode** leaves transcription untouched.
- **Custom instructions** tell your cleanup model how to edit the transcript.
- **S1-mini** offers preset style, structure, and context choices for English text.

Freehand delivers raw text when cleanup is disabled or falls back to it when cleanup fails, times out, or returns empty output. Retaining both versions after successful cleanup requires history to be enabled before the run and the text to fit its memory limits. Read [Transcript post-processing](../post-processing/) before configuring S1-mini or a local llama.cpp route.

## History

:::tip[Keep both transcript versions for this session]
Enable history before a run if you want to compare raw and cleaned text.
History is off by default, stays in memory, holds at most 20 entries and 2 MiB,
and is cleared when Freehand exits. Copy anything you want to keep before quitting.
:::

Open **History** from the activity rail. Its sidebar combines history controls
with the retained transcript list. Search transcript text or an audio file's
name, and filter by **All**, **Voice**, or **Audio files**. Search includes the
final, raw, and cleaned versions already in memory; it does not search files on
disk or recover transcripts from earlier sessions.

Select an entry to read its full transcript in the main area. The right sidebar
offers **Details** for that run and **History settings** for retention. Details
open automatically when you enter History in a window at least 1100px wide.
Close them with **X** to keep them hidden while browsing that visit, and choose
**Details** above the transcript to reopen them. In narrower windows, details
start hidden; **Details** opens them as an overlay on the right.
At compact sizes, use the left sidebar button to open the list over
the main area, then choose a transcript. You can also browse **Recent** in the
bottom panel in workflows, Connections, Local runtime, and History, where the latest transcript opens automatically and
older entries expand when selected.

The sidebar shows whether retention is on, opens **History settings**, and offers
**Clear history** to remove all retained entries. Filtering the list does not
change what is retained.

The selected transcript keeps **Listen** and **Copy** directly available. Open the
ellipsis **Transcript actions** menu for **Remove from history**. **Compare** opens
raw and cleaned text together, with separate copy controls. If cleanup fails, its
explanation appears below the raw transcript. In Recent, **Transcription details**
in the action menu still opens its separate window.

History never retains audio, credentials, full file paths, or destination
details. Each copy action is explicit.

## Finding and adjusting settings

Open **Settings** from the activity rail, tray, or command palette for **General**,
**Shortcuts**, **Overlay**, and **Vocabulary**. Workflow configuration stays in the
right options sidebar, and saved servers have their own **Connections** page.
The **Settings** cog in each Voice, Audio file, or Text to speech page opens its
options directly, including during first-run setup. The title-bar right-sidebar
toggle offers the same access.
Shared Vocabulary and Overlay controls can also open beside the workflow, so you
can adjust them without leaving the current transcript.
Choose **Save** to apply edits. Closing options or navigating away with unsaved
edits offers **Save**, **Discard**, or **Keep editing**. A failed save retains the
editable draft; correct the indicated field and retry. While saving, the
confirmation stays open until the save finishes; Escape and clicks outside it
do not dismiss it.

In Settings, **Find settings** filters the sidebar by page
name or terms such as “glow” and “hotkey.” Enter opens the first match;
Escape clears the filter.

Voice's **Audio** options keep microphone selection, the recording limit, and the main silence
switches together. Open **Speech detection tuning** for sensitivity, padding,
minimum speech, and segment timing. Enabled automatic stop keeps its pause
control beside the switch.

**Overlay** keeps preview, layout, position, and size up front. Open **Appearance
and behavior** for surface, visualizer, visible phases, motion, spacing, opacity,
and glow. Preview shows your changes before you save them. Glow is unavailable
with a Minimal surface.

Model pickers list models advertised by your server; you can also enter an exact
model ID. Listing models does not run them. Choose the matching
[model profile](../../models/) to see the options Freehand supports for that model.
Language pickers search by name or code; see [Languages](../languages/) for custom
server values and model restrictions.

Open **Request settings** to adjust timeouts or view connection diagnostics.
Audio-file **Transcription controls** include context and temperature; Voice
keeps context hints visible and temperature under **Request settings**.
Cleanup's **Generation controls** include output limits and reasoning options.

## Text to speech

Text to speech is off by default. Configure a speech service, model, and voice
to generate audio from your own text or listen to transcripts.

<Steps>

1. **Open Text to speech**, then choose **Configure speech** in the composer or
   **Connection** or **Model** in its sidebar to open **Speech** options on the right.
   Select a saved connection or **Add connection…**, then
   choose the model and voice.
   **Refresh models** and supported **Refresh voices** read metadata without generating
   audio; manual IDs work too. For initial setup, choose
   the model profile, turn on **Enable text to speech**, and save your changes.
2. **Enter the text you want to hear.** You can draft before setup is complete;
   compact guidance beside **Configure speech** explains what to configure. Your unsent text
   survives switching tasks or visiting Settings, and is cleared when the window
   reloads or Freehand exits.
3. **Choose Speak** or press **Ctrl+Enter** in the editor to generate and play the audio.
   **Enter** on its own adds a new line.
4. **Use the playback controls** to pause, resume, seek, restart, stop, or explicitly
   **Save generated speech** to a file.

</Steps>

Text to speech accepts up to 4,096 Unicode characters. Longer drafts remain
editable; shorten the text to enable Speak.

To try a voice before saving settings, turn on **Enable text to speech** in the
form and choose **Preview** beside the voice selector. This sends a fixed sample
phrase to the selected speech service using your unsaved choices. It does not
save settings or enable playback elsewhere. Stop and preview again to hear changes.

You can edit, select, copy, or clear the draft while speech is being generated,
playing, or paused. Those edits do not change the current audio. Once generation
finishes, **Speak** or **Ctrl+Enter** generates the text currently in the editor and
replaces the previous audio, including when playback is paused. Playback controls
and **Save generated speech** continue to operate on the existing audio until then.

Open **Playback actions** for Restart or Save, or to clear
completed audio from memory. Completed audio also has a direct replay button.

Drag the playback slider to choose a position; playback moves there when you release it.
With the slider focused, use the arrow keys to adjust the position, **Home** for the
start, or **End** for the end. Seeking during playback continues playing. Seeking
while paused or after completion leaves the audio paused until you choose **Resume**.
Seeking uses the audio already in memory, and **Save generated speech** always saves
the full audio.

You can also choose **Listen** on a completed Voice or Audio-file result, even
with history off, or on a retained history entry. Generated audio remains in memory until you clear or replace it, start a
recording, or exit Freehand.

Use the player's **Stop** control to cancel active speech generation.

Playback starts on demand. Freehand does not automatically read every transcript aloud or provide a voice conversation mode.

## Action feedback

Speech failures appear beside the playback controls. Open **Details** for the
full explanation and a shortcut to **Speech settings**. In the speech composer,
**Try again** generates speech from the text currently in the editor; a failed
request does not erase your draft. File and dictation errors also provide
**Details** with a shortcut to their transcription settings. A discarded
microphone recording cannot be retried; **Record again** starts a new recording
after you correct the problem.

See [Troubleshooting](../troubleshooting/) for connection, microphone, and
delivery problems.

## Status overlay and tray

The recording overlay shows when Freehand is recording, processing, or waiting
for you to copy a result. It is enabled by default and does not take focus from
your application. Change its layout, position, appearance, and visibility under
**Settings → Overlay**. [Live transcription](../live-transcription/) can also
show captions as you speak.

Error and **needs copy** notifications disappear after five seconds. The error
or transcript stays available in Freehand, so you can return to it and copy later.
A new recording attempt shows fresh feedback. Recording and processing overlays
remain visible while work is active.

Click the Windows tray icon or macOS menu-bar icon for a compact Freehand panel
with recording controls, Voice connection/model selection, and the latest result
with Copy.
**Open Freehand** opens the full workspace; **Settings** opens preferences.
Escape or clicking outside dismisses the panel without cancelling work. The panel
dismisses before recording starts or stops; normal application/window delivery
checks still apply. Right-click the icon for the native menu, including Quit.

On Windows, the panel takes keyboard focus so you can type a model name. Recording
uses the text field focused after the panel closes; it does not force a return to
the application you were using before opening it. To choose the destination
directly, focus its text field and use your recording shortcut.

The right-click menu can show or hide Freehand, open Settings or About, cancel
active work, copy an available recovery transcript, and quit.

:::note[Quit from the tray]
Choose **Quit** from the tray menu to exit Freehand. Closing the window hides
Freehand after resolving any unsaved settings; Freehand continues running. Quit cancels active
transcription and speech work. If you are saving generated audio, let the save
finish before quitting; an interrupted export can leave a partial WAV file.
:::

## Appearance

Under **Settings → General**, choose System, Light, or Dark. On Windows, you can
also enable Mica for a translucent window background. Native window appearance
changes take effect after quitting from the tray and reopening Freehand.
