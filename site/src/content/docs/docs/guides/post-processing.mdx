The app can optionally pass each successful raw speech-to-text result to a separate OpenAI-compatible `POST /chat/completions` endpoint before delivery. Speech recognition and cleanup have independent endpoints, models, and credentials. The raw transcript is retained first when history is enabled.

If post-processing fails, is unavailable, or returns empty text, the run falls
back to the raw transcript. Delivery still follows the normal destination
checks or explicit-copy setting; cancellation prevents automatic insertion.

## Choose a workflow

| Choice                        | Configuration                                                                                             |
| ----------------------------- | --------------------------------------------------------------------------------------------------------- |
| Leave transcription unchanged | Keep **Cleanup** off; no chat endpoint is needed.                                                         |
| Use your own cleanup model    | Enable processing, select **Generic**, and supply a compatible chat endpoint and model.                   |
| Use S1-mini by Superwhisper   | Enable processing, select its dedicated profile, and connect a server hosting that English cleanup model. |

:::tip[Compare both versions]
Cleanup changes text and can make mistakes. Enable **History** before a run if
you want to compare or copy the raw and cleaned versions after successful
processing. History is off by default, limited to 20 entries and 2 MiB, and
cleared when Freehand exits. Raw fallback on cleanup failure does not require
history.
:::

## Custom-instruction processor

First create a **Cleanup** connection under **Settings → Connections**:

<Steps>

1. Choose **New connection**, name it, select **Cleanup**, and choose the server profile.
2. Enter the processor's OpenAI-compatible base URL, normally ending in `/v1`.
3. Enable **Allow insecure HTTP** only for a trusted local or LAN server using `http://`.
4. Add the processor's API key when that endpoint requires one.
5. Choose **Save connection**. Open **Settings → Cleanup**, select that active connection, enable cleanup, and list models or enter the exact model ID. Model listing reads metadata; it does not test cleanup quality.
6. Choose **Generic** and write the system instruction for the selected model. Freehand shows the UTF-8 storage limit, validates empty or oversized instructions, and can restore the recommended instruction.
7. Choose **Save settings**. Dictate a short example and review the result before using cleanup for longer text.

</Steps>

The system instruction is stored with the rest of the ordinary Freehand settings; the API key remains in Windows Credential Manager. The app sends a non-streaming chat completion with temperature `0`. The raw transcript is the separate user message, so the instruction does not need a transcript placeholder. Freehand does not send the speech-to-text credential to the processor.

Endpoint model IDs and request behavior are deliberately independent. A local or remote server may assign any model ID, so Freehand never guesses that a model needs the S1-mini contract from its name. Switching profiles preserves each profile's stored controls so switching back does not discard the custom instruction or S1-mini choices.

## S1-mini by Superwhisper with llama.cpp

Choose the **S1-mini by Superwhisper** model profile for English cleanup with
styling, structure, and context controls. The [S1-mini model guide](../../models/s1-mini/)
explains these controls and links to launch recipes for llama.cpp and vLLM.
For an existing Generic endpoint, disable reasoning on the server.

## Generation controls

Open **Settings → Cleanup → Generation controls**. Save before starting a
new recording or stored-file job; an active job keeps the settings captured at
its start, even if cleanup runs later.

**Limit output tokens** is optional for Generic, llama.cpp, and vLLM. Turning it on
initially supplies 2,048 tokens; adjust this for your selected model and the
length of the complete cleaned transcript. The accepted range is 1–65,536 whole
tokens, not words. Turning it off uses the server's limit and retains a valid
number for later. This setting neither enlarges the model's context window nor
splits long inputs. The request timeout remains independent. A limit that is too
small can cause an incomplete response and raw-transcript fallback.

**Disable reasoning** is optional for Generic cleanup under the llama.cpp or vLLM
profile. It asks the model to return its result without a thinking phase, using
a supported server/template contract. Off retains the server's configured behavior.

For **S1-mini**, thinking disabled is a requirement, not a preference. Under
llama.cpp or vLLM, the control is marked **Required off** and cannot be switched off; each
request enforces it independently of the optional custom-model setting. Under
Generic, Settings shows **Disable on server**, and the server must enforce it.
The exact S1 prompt, trained styling/structure/context values, and temperature
zero stay fixed. No extra sampling controls are introduced.

When switching from llama.cpp or vLLM to Generic with the custom reasoning override
saved, turn that override off before saving. A provider rejection or reported
output truncation uses the existing raw-text fallback; Freehand does not silently
retry with different controls. Optional controls remain off for older settings,
while S1-mini through llama.cpp or vLLM gains its required reasoning-off request.

Consult [llama.cpp generation controls](../../backends/llama-cpp/#cleanup-generation-controls)
for the inspected server revision and model/template limits.

## vLLM cleanup

Select **vLLM** as the post-processing compatibility profile to use a qualified
v0.28.0 server. Configure its `/v1` endpoint and chosen text model separately from
transcription. The generation controls above also apply, including mandatory
reasoning off for the S1-mini preset. See the [vLLM guide](../../backends/vllm/)
for connection setup and server options.

## Language compatibility

S1-mini cleanup supports English only. Non-English selections or reported
languages use raw text instead. With no known language, S1-mini runs assuming
English, as stated in its controls. Custom cleanup depends on the selected
model and instruction. See [language selection](../languages/).

The **Model profile** field uses the same model-behavior contract as transcription
and speech playback. See [model profiles](../../models/) for how it differs
from a connection’s backend profile.
