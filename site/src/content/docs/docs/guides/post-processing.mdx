Turn on **Cleanup** to edit a transcript before Freehand delivers it. Cleanup
uses a chat model on a service you choose, separate from speech recognition.
It sends transcript text to that service, not the original audio. You can use
your own instructions or S1-mini's English cleanup controls.

If post-processing fails, is unavailable, or returns empty text, the run falls
back to the raw transcript. Delivery still follows the normal destination
checks or explicit-copy setting; cancellation prevents automatic insertion.

## Choose a workflow

| Choice                        | Configuration                                                                                             |
| ----------------------------- | --------------------------------------------------------------------------------------------------------- |
| Leave transcription unchanged | Keep **Cleanup** off; no chat endpoint is needed.                                                         |
| Use your own cleanup model    | Enable processing, select **Generic**, and supply a compatible chat endpoint and model.                   |
| Use S1-mini by Superwhisper   | Enable processing, select its dedicated profile, and connect a server hosting that English cleanup model. |

:::tip[Compare both versions]
Cleanup changes text and can make mistakes. Enable **History** before a run if
you want to compare or copy the raw and cleaned versions after successful
processing. History is off by default, limited to 20 entries and 2 MiB, and
cleared when Freehand exits. Raw fallback on cleanup failure does not require
history.
:::

## Custom-instruction processor

Set up a connection for cleanup, then choose the model and instruction:

<Steps>

1. Open **Settings → Cleanup** and choose **Add connection…** in the connection picker.
   Name the connection and choose its backend profile.
2. Enter the processor's OpenAI-compatible base URL, normally ending in `/v1`.
3. Enable **Allow HTTP for this connection** only for a trusted local or LAN server
   using `http://`. HTTP sends text and credentials without transport encryption.
4. Select **Authentication → API key** and enter the key if the endpoint requires one.
5. Choose **Save and return**, then enable cleanup. Use **Refresh models** or enter
   the exact model ID. Refreshing reads metadata; it does not test cleanup quality.
6. Choose **Generic** under **Model profile** and write the **Custom system instruction**.
   You can restore the recommended instruction if you need a starting point.
7. Choose **Save** (or **Save and return** when opened from a task). Dictate a short example and review the result before
   using cleanup for longer text.

</Steps>

The instruction is saved locally in settings; the API key stays in Windows
Credential Manager or macOS Keychain. Write instructions for how to edit the
text, without a transcript placeholder. Freehand supplies the raw transcript
separately and uses the selected cleanup connection's credentials.

Select the model profile explicitly. Freehand does not recognize S1-mini from
the model's name. Switching profiles preserves your custom instruction and
S1-mini choices for when you switch back.

## S1-mini by Superwhisper with llama.cpp

Choose the **S1-mini by Superwhisper** model profile for English cleanup with
styling, structure, and context controls. The [S1-mini model guide](../../models/s1-mini/)
explains these controls and links to launch recipes for llama.cpp and vLLM.
For an existing Generic endpoint, disable reasoning on the server.

## Generation controls

Open **Settings → Cleanup → Generation controls**. Save before starting a
new recording or audio-file job; changes do not affect work already running,
even if cleanup has not started yet.

**Limit output tokens** is optional for Generic, llama.cpp, and vLLM. Turning it on
initially supplies 2,048 tokens; adjust this for your selected model and the
length of the complete cleaned transcript. The accepted range is 1–65,536 whole
tokens, not words. Turning it off uses the server's limit and retains a valid
number for later. This setting neither enlarges the model's context window nor
splits long inputs. The request timeout remains independent. A limit that is too
small can cause an incomplete response and raw-transcript fallback.

**Disable reasoning** is optional for the Generic model profile with a llama.cpp
or vLLM backend. It asks the model to return its result without a thinking phase.
Support depends on your server and model template. Leaving it off uses the
server's configured behavior.

For **S1-mini**, reasoning must be off. With a llama.cpp or vLLM backend,
**Required off** means Freehand requests this automatically. With a Generic
backend, **Disable on server** means you must configure the server to turn it off.

When switching from llama.cpp or vLLM to Generic with the custom reasoning override
saved, turn that override off before saving. A provider rejection or reported
output truncation uses the existing raw-text fallback; Freehand does not silently
retry with different controls. Review cleaned output against the raw transcript:
Freehand cannot detect omissions that the server does not report.

Consult [llama.cpp generation controls](../../backends/llama-cpp/#cleanup-generation-controls)
for supported server versions and model limits.

## vLLM cleanup

Select **vLLM** as the cleanup connection's backend profile for a supported
v0.28.0 server. Configure its `/v1` endpoint and chosen text model separately from
transcription. The generation controls above also apply, including mandatory
reasoning off for the S1-mini preset. See the [vLLM guide](../../backends/vllm/)
for connection setup and server options.

## Language compatibility

S1-mini cleanup supports English only. Non-English selections or reported
languages use raw text instead. With no known language, S1-mini runs assuming
English, as stated in its controls. Custom cleanup depends on the selected
model and instruction. See [language selection](../languages/).

See [model profiles](../../models/) if you are unsure which cleanup profile to choose.
