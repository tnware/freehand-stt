Freehand is a lightweight Windows and macOS client for speech-to-text and text-to-speech
services you choose. Start with voice dictation, transcribe an audio file, or
generate speech from text. For local recognition and cleanup, choose an optional
[managed local runtime](../guides/local-runtime/) instead of configuring a server.
Available runtimes vary by platform. Models are not bundled with Freehand;
runtime installation and model downloads are explicit setup actions.

Freehand is **free forever and open source**, with no Freehand subscription or
account. Your chosen provider or hosting may have its own costs. A dedicated
local GPU is not required: connect to another machine or a compatible hosted
service if your PC lacks the resources, or you want to keep them for other work.

## What you need

- Windows 11 x64 with WebView2, or macOS 13+ on Apple Silicon or Intel.
- A [managed local runtime](../guides/local-runtime/) for recognition or cleanup,
  or a reachable compatible service for your task (see the [backend guides](../backends/)).
  Text to speech requires a manually configured service.
- For a manual service: its base URL, model ID (except whisper.cpp's server-loaded model), and API key
  when authentication is required.

| Task | Additional requirements | Start here |
| --- | --- | --- |
| Voice dictation (default) | Speech-to-text service and a usable microphone; a recording shortcut is optional | [Run your first dictation](#run-your-first-dictation) |
| Audio file transcription | Speech-to-text service and a supported audio file; no microphone or recording shortcut | [Transcribe a stored audio file](#transcribe-a-stored-audio-file) |
| Text to speech (optional) | Speech synthesis service, model and voice ID, and text to speak; no transcription setup | [Generate speech](#generate-speech) |

:::caution[Download verification and signing]
Choose the Windows installer/portable executable or the macOS ZIP matching your architecture. Download only from the official project and verify against `SHA256SUMS` from the same release. Windows assets are not Authenticode-signed; macOS apps are ad-hoc-signed, not Developer ID-signed or notarized. Older releases may lack macOS assets.
:::

Download from the [Releases page](https://github.com/tnware/freehand-stt/releases),
then follow [Windows installation](../guides/windows-installer/) or
[macOS installation and permissions](../guides/macos-setup/).

## First launch

:::caution[Settings reset for earlier alpha installations]
This version starts with fresh settings. Add your connections, choose models,
review preferences, and enter API keys again. Earlier alpha settings and saved
keys are left untouched but are not imported or reused.
:::

Freehand opens **Voice** with a **Set up voice transcription** screen. To work
with a recording or generate speech instead, choose **Audio file** or **Text to
speech** at the top. You can set up each task independently.

For the recommended local setup on Windows or macOS, follow
[Local runtimes](../guides/local-runtime/) to install NeMo, download
Nemotron 3.5 Streaming, and enable live microphone transcription without entering
a server URL. Select its built-in Connection separately for Voice and Audio file;
files use the runtime's selected model in completed mode. Optional local cleanup
uses managed llama.cpp with S1-mini. Speech generation needs a manually configured
service.

To connect a manual service from your chosen task:

<Steps>

1. **Add a server.** Open the task's connection picker and choose **Add connection…**.
   Name it, choose its **Backend**, and enter its base URL and authentication
   details. Choose **Save and return** to continue to model settings.
2. **Choose a model.** Select a model listed by your server or enter its exact ID.
   With whisper.cpp, Freehand uses the model already loaded by the server.
   Review the [model profile](../models/) and choose **Save and return**.

</Steps>

:::note[Connection checks read metadata]
The connection check never submits audio and never invokes a discovered model.
A successful check does not test transcription quality.
:::

Voice and Audio file keep separate model and connection choices. To use the
same server for both, [enable both uses on the saved connection](../guides/saved-connections/#reuse-a-server),
then select it in each task.

## Choose the recording language

Under **Settings → Voice transcription** or **Audio-file transcription**, search
the language picker by name or code, or choose
**Server default** or **Automatic detection**. Your model must support the
language. If you use S1-mini cleanup, its only supported language is English.
See [language selection](../guides/languages/) for detection and fallback behavior.

## Configure the speech endpoint

For Generic, Speaches, and vLLM transcription, include the OpenAI API prefix in
the base URL, typically:

```text title="Speech endpoint base URL"
https://speech.example.com/v1
```

Enter the base URL, not the full `/audio/transcriptions` address. Freehand adds
the route for you.

For whisper.cpp, use the server root without `/v1`; Freehand uses `/inference`
and the server-loaded model instead.

HTTPS is required by default. Enable **Allow HTTP for this connection** only for
a trusted local or LAN service. HTTP sends credentials and audio without
encryption, so do not enable it for an untrusted network.

See [Connect a speech server](../guides/connect-a-server/) for other backends,
local and remote server setup, and connection checks.

## Choose your transcript workflow

Leave **Cleanup** off for your first dictation or file transcription. Freehand
delivers the speech model's transcript unchanged; no chat service is needed.

Later, **Settings → Cleanup** can add an independently configured chat service
after STT. Choose [custom instructions](../guides/post-processing/#custom-instruction-processor)
or the optional English-only [S1-mini profile](../guides/post-processing/#s1-mini-by-superwhisper-with-llamacpp).
If cleanup fails, times out, or returns empty output, Freehand falls back to the
raw transcript. Cleanup is not required for any of the three tasks.

## Run your first dictation

In **Voice**, choose your connection and model in the setup screen. Changes there
apply immediately. Expand **Transcription options** for language, realtime, and
recognition hints supported by your selected model profile.

Follow **Next step** to check your microphone and recording shortcut. On macOS,
also grant the requested [permissions](../guides/macos-setup/#native-permissions).
**Ctrl+Shift+Space** is the default toggle shortcut. Save any settings edits
with **Save and return**.

If that shortcut conflicts with another application, record a different chord
under **Settings → Shortcuts**, or choose **Clear** and save it unassigned.
You can finish setup without a shortcut and use the on-screen recording controls.
For dictation into another application, start with its text field focused using
a working shortcut; otherwise review the transcript and copy it explicitly.

Choose **Check connection** to test access without running a model. If the check
fails, correct the problem and choose **Check again**. **Finish setup** appears
once the required checks pass; recording becomes available after that change is
saved.

Now dictate into another application:

<Steps>

1. Focus the text field where the result should go.
2. Start the configured toggle shortcut, or hold the configured hold-to-talk chord.
3. Speak.
4. Stop the toggle recording, or release the hold-to-talk chord.
5. Wait while Freehand transcribes the audio.

</Steps>

Keep the destination focused until your text appears. If Freehand cannot safely
insert it, choose **Copy** on the result and paste it yourself. Check for partially
inserted text first. Windows requires the original text field; macOS allows you
to move between fields in the same window. See
[safe text insertion](../guides/privacy-and-safety/#safe-text-insertion) for details.

## Transcribe a stored audio file

You do not need a microphone, recording shortcut, or completed dictation setup.

<Steps>

1. **Open Audio file** and select its speech-to-text connection and model.
   This selection is separate from Voice, even when you use the same server.
2. **Select Choose** to open a FLAC, MP3, MP4, MPEG, MPGA, M4A, OGG, WAV, or
   WebM file. Selecting it does not upload it.
3. **Choose Transcribe** and wait for the result. Start with completed output;
   compatible streaming is optional.
4. **Copy** the completed transcript into the application you want.

</Steps>

File transcripts are available to copy; Freehand does not insert them automatically.

## Generate speech

Text to speech is optional and off by default. It needs a speech synthesis
connection, not a microphone, recording shortcut, or STT setup.

<Steps>

1. **Open Text to speech** and add or select its connection as above.
2. **Open Speech → All speech settings**. Choose the model and voice ID, turn on
   **Enable text to speech**, and choose **Save and return**.
3. **Enter your text**, then choose **Speak** to generate and play audio.
4. **Use the playback controls** to pause, resume, restart, stop, or explicitly
   **Save generated speech** to a file.

</Steps>

You can also use **Listen** on completed transcripts, with or without history.
See [Text to speech](../guides/using-freehand/#text-to-speech) for playback,
previewing voices, and saving audio.

## Optional features

Local voice activity detection and the native status overlay are **on by
default**. You can configure or disable either. Voice detection alone does not
enable automatic stop, silence trimming, or checkpoints.

| Feature | Initial setting |
| --- | --- |
| Local voice detection and status overlay | On |
| Silence trimming, automatic stop, and pause-aware checkpoints | Off |
| Transcript cleanup and memory-only history | Off |
| Audio-file transcript | Shown when complete; text updates are optional |
| Text-to-speech playback and Windows Mica material | Off |
| Insert dictation into the original application | On, when the destination is still focused and safe |
| Automatic update checks | On; configurable under **Settings → General** |
