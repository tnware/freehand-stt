Freehand turns speech into text and text into speech using a service you choose.
Install the app, connect a service or set up a local runtime, then try one task.
You can use each task independently.

## What you need

- **A supported computer:** Windows 11 x64 with WebView2, or macOS 13+ on Apple Silicon or Intel.
- **Somewhere to run speech:** a [local runtime](../guides/local-runtime/) managed by Freehand,
  or a compatible service on your computer, another machine, or a hosted provider.
- **For dictation:** a microphone. Audio files and text to speech do not need one.

Freehand is free and open source, with no account or subscription. Your chosen
provider or hosting may charge for use. A local GPU is not required when you
connect to another machine or a hosted service.

## First launch

Freehand opens **Voice** with **Set up voice transcription**. Choose **Audio file**
or **Text to speech** on the left if you want to start with a different task.

Choose where processing will run:

<Tabs>
  <TabItem label="Set up a local runtime">

Freehand can install and manage a supported runtime on this computer.
Runtime binaries and models are separate, explicit downloads; neither is
bundled with the app.

<Steps>

1. **Open Local runtime.** Follow [local runtime setup](../guides/local-runtime/#set-up-local-transcription)
   to install NeMo and download the recommended Nemotron 3.5 Streaming model.
2. **Start the runtime.** Wait for **Running**, then select its built-in
   **NeMo-Speech.cpp** Connection in Voice. No URL or API key is needed.
3. **Enable realtime for live dictation.** Turn on **Realtime transcription**
   in Voice's Transcription options and finish microphone setup below.

</Steps>

For speech generation, [add MagpieTTS to NeMo](../guides/local-runtime/#local-speech-with-magpietts).
The local runtime guide also covers whisper.cpp transcription and optional S1-mini cleanup.

  </TabItem>
  <TabItem label="Connect an existing service">

Have the service's **base URL**, **model ID**, and **API key** if it requires one.
The service can run locally, on your network, or with a hosted provider.

<Steps>

1. **Add the connection.** In your task's connection picker, choose
   **Add connection…**. Name it, choose its **Backend**, enter its URL and
   authentication, then choose **Save and return**.
2. **Choose the model.** Select or enter the exact model ID and review its
   [model profile](../models/). whisper.cpp uses its server-loaded model instead.
3. **Save the options.** Use **Save** in the options sidebar. First-run model
   selections apply immediately.

</Steps>

Use [Connect a speech server](../guides/connect-a-server/) for endpoint examples
and connection checks, or [backend guides](../backends/) to run a server yourself.

  </TabItem>
</Tabs>

Each task selects its own connection. To share a manual service, enable the
needed [connection uses](../guides/saved-connections/#reuse-a-server) and select
it in each task. A managed connection supplies its runtime's selected model.

:::note[Coming from an earlier alpha?]
This version starts with fresh settings. Add your connections, models,
preferences, and API keys again. Earlier alpha settings and saved keys remain
untouched and are not imported.
:::

### Configure the speech endpoint

For a manual connection, enter the **base URL**, not the full transcription
route. Most transcription backends use a `/v1` prefix; whisper.cpp uses the
server root. Follow the [URL examples](../guides/connect-a-server/) for your backend.
HTTPS is the default. Allow HTTP only on a trusted local or LAN connection:
it sends audio and credentials without encryption.

### Choose the recording language

Open your task's **Settings** cog, then **Transcription**, and choose a supported
language, **Server default**, or **Automatic detection**.
[Language selection](../guides/languages/) explains which choice to use.
S1-mini cleanup supports English only.

### Choose your transcript workflow

Leave **Cleanup** off for your first attempt to receive the speech model's
transcript unchanged. You can [add cleanup](../guides/post-processing/) later;
if it fails, Freehand falls back to the raw transcript.

## Run your first dictation

<Steps>

1. **Finish Voice setup.** Select your connection and model, then follow
   **Next step** to check the microphone and shortcut. On macOS, grant the
   requested [permissions](../guides/macos-setup/#native-permissions).
2. **Check the connection.** Choose **Check connection**, resolve any reported
   problem, then **Finish setup** and save. The check reads metadata; it does
   not submit audio or run a model.
3. **Focus the destination.** Click the text field in the application where
   your words should appear.
4. **Record a short phrase.** Press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Space</kbd>
   to start, then press it again to stop. If you changed the shortcut, use that chord.
5. **Keep the destination focused.** Wait for transcription and delivery.

</Steps>

**Expected result:** your text appears in the destination. If insertion is
blocked, check for partially inserted text, choose **Copy**, and paste it yourself.
Freehand will not redirect the result to a different focused window. See
[safe text insertion](../guides/privacy-and-safety/#safe-text-insertion).

:::tip[No working shortcut?]
Change or clear it under **Settings → Shortcuts**. You can finish setup with
no shortcut and use the on-screen controls, then copy the result explicitly.
See [recording and shortcut options](../guides/using-freehand/).
:::

## Transcribe a stored audio file

Open **Audio file**, select its transcription connection and model, then
**Choose** a file. Selecting a file does not upload it; **Transcribe** starts
the request. **Copy** the finished result yourself.

<LinkCard title="Transcribe an audio file" href="../guides/audio-files/" description="Supported formats, file limits, streaming text, cancellation, and recovery." />

## Generate speech

Open **Text to speech → Configure speech**, select a speech connection, model,
and voice, then turn on **Enable text to speech** and **Save**. Enter text and
choose **Speak**. Playback is optional and off by default.

<LinkCard title="Generate and play speech" href="../guides/text-to-speech/" description="Choose a voice, preview it, listen to transcripts, and save generated audio." />

## Optional features

Start with one successful request, then adjust the options you need.

| Feature | Initial setting | Learn more |
| --- | --- | --- |
| Local voice detection and status overlay | On | [Voice controls](../guides/using-freehand/) |
| Silence trimming, automatic stop, pause-aware checkpoints | Off | [Recording options](../guides/using-freehand/#long-dictation-and-vad) |
| Transcript cleanup | Off | [Cleanup](../guides/post-processing/) |
| Memory-only transcript history | Off | [History](../guides/history/) |
| Audio-file text updates | Completed output; streaming optional | [Audio files](../guides/audio-files/) |
| Text-to-speech playback | Off | [Text to speech](../guides/text-to-speech/) |
| Insert dictation into the original application | On, when focused and safe | [Delivery rules](../guides/privacy-and-safety/#safe-text-insertion) |
| Automatic update checks | On | [Workspace and settings](../guides/workspace/) |
| Windows Mica material | Off | [Workspace appearance](../guides/workspace/) |

Voice detection alone does not enable automatic stop, trimming, or checkpoints.
