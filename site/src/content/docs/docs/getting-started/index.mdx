Freehand is a lightweight Windows client for speech-to-text and text-to-speech
services you choose. Start with voice dictation, transcribe an audio file, or
generate speech from text. It does not install or run a model for you.

Freehand is **free forever and open source**, with no Freehand subscription or
account. Your chosen provider or hosting may have its own costs. A dedicated
local GPU is not required: connect to another machine or a compatible hosted
service if your PC lacks the resources, or you want to keep them for other work.

## What you need

- Windows 11 with WebView2.
- A reachable compatible service for your task (see the [backend guides](../backends/)).
- Its base URL, model ID (except whisper.cpp's server-loaded model), and API key
  when authentication is required.

| Task | Additional requirements | Start here |
| --- | --- | --- |
| Voice dictation (default) | Speech-to-text service, a usable microphone, and a recording shortcut | [Run your first dictation](#run-your-first-dictation) |
| Audio file transcription | Speech-to-text service and a supported audio file; no microphone or recording shortcut | [Transcribe a stored audio file](#transcribe-a-stored-audio-file) |
| Text to speech (optional) | Speech synthesis service, model and voice ID, and text to speak; no transcription setup | [Generate speech](#generate-speech) |

:::caution[Alpha distribution]
Freehand's GitHub Releases provide an unsigned executable and per-user Windows installer. Download only from the official project, verify the corresponding entry in `SHA256SUMS`, and expect Windows to identify the publisher as unknown until Authenticode signing is introduced.
:::

Download the latest Windows alpha from the
[Releases page](https://github.com/tnware/freehand-stt/releases). The installer
is the normal first-install path. The bare executable exists for portable use
and for Freehand's in-app updater.

## First launch

Freehand opens **Voice**, its default task, with a **Set up dictation** screen.
The **Audio file** and **Text to speech** tabs remain available before you finish
dictation setup. Choose the task you want; **Finish setup** belongs to dictation,
not to every workflow.

To connect a service from your chosen task:

<Steps>

1. **Add a server** — open the task's connection picker and choose **Add connection…**. Name it, select its compatibility profile, and enter the base URL. The task's use is preselected. Configure authentication and HTTP permission as required, then choose **Save and use connection**. Keys use Windows Credential Manager.
2. **Choose a model** — for Voice or Audio file, use **Test** to read model metadata or enter the model ID directly. Home quick controls apply immediately; whisper.cpp uses its server-loaded model. For Text to speech, open **Model and voice settings** to configure its model, voice, and enable switch. Settings-page edits apply with **Save settings**.

</Steps>

:::note[Connection checks read metadata]
The connection check never submits audio and never invokes a discovered model.
A successful check does not test transcription quality.
:::

Voice and Audio file share the same speech-to-text connection and model. Optional
cleanup is a separate stage after transcription; Text to speech has its own
connection and settings and can be used without either STT or cleanup.

## Choose the recording language

For dictation and audio files, under **Settings → Transcription → Language**,
search by name or code, or choose
**Server default** or **Automatic detection**. Your model must support the
language. If you use S1-mini cleanup, its only supported language is English.
See [language selection](../guides/languages/) for detection and fallback behavior.

## Configure the speech endpoint

For Generic, Speaches, and vLLM transcription, include the OpenAI API prefix in
the base URL, typically:

```text title="Speech endpoint base URL"
https://speech.example.com/v1
```

It joins the transcription route as:

```http title="Request route built by Freehand"
POST https://speech.example.com/v1/audio/transcriptions
```

Set the exact model ID expected by your gateway. Model discovery is bounded metadata; selecting a discovered ID does not run it.

For whisper.cpp, use the server root without `/v1`; Freehand uses `/inference`
and the server-loaded model instead.

HTTPS is required by default. **Allow insecure HTTP** is an explicit opt-in for a trusted local or LAN service. It sends credentials and audio without transport encryption, so do not enable it for an untrusted network.

See [Connect a speech server](../guides/connect-a-server/) for shared-gateway
and separate-service layouts, a [CPU speech-server example](../guides/connect-a-server/#example-speaches-on-your-pc), the evidence-labeled compatibility list, and a
failure guide.

## Choose your transcript workflow

Leave **Cleanup** off for your first dictation or file transcription. Freehand
delivers the speech model's transcript unchanged; no chat service is needed.

Later, **Settings → Cleanup** can add an independently configured chat service
after STT. Choose [custom instructions](../guides/post-processing/#custom-instruction-processor)
or the optional English-only [S1-mini profile](../guides/post-processing/#s1-mini-by-superwhisper-with-llamacpp).
If cleanup fails, times out, or returns empty output, Freehand falls back to the
raw transcript. Cleanup is not required for any of the three tasks.

## Run your first dictation

In **Voice**, configure the STT connection and model as above, then complete the
dictation-only readiness items:

1. Select **System default** or a specific microphone under **Settings → Audio**.
2. Keep **Ctrl+Shift+Space** for toggle recording, or configure another toggle
   shortcut and an optional hold-to-talk chord under **Settings → Shortcuts**.
3. Choose **Save settings** for Settings-page edits and return to **Voice**.
4. Choose **Test connection**. Correct any failure and retry, then choose
   **Finish setup** when all dictation requirements are ready.

Now dictate into another application:

<Steps>

1. Focus the text field where the result should go.
2. Start the configured toggle shortcut, or hold the configured hold-to-talk chord.
3. Speak.
4. Stop the toggle recording, or release the hold-to-talk chord.
5. Wait while Freehand transcribes the audio.

</Steps>

If the same safe target still owns focus, Freehand inserts the text with Unicode input. If focus or process identity changed, it fails closed and leaves the transcript available for explicit copying.

## Transcribe a stored audio file

You do not need a microphone, recording shortcut, or completed dictation setup.

<Steps>

1. **Open Audio file** and configure the STT connection and model as above, if
   you have not already done so for Voice.
2. **Choose audio** to select a FLAC, MP3, MP4, MPEG, MPGA, M4A, OGG, WAV, or
   WebM file through the native picker. Selecting it does not upload it.
3. **Choose Transcribe** and wait for the result. Start with completed output;
   compatible streaming is optional.
4. **Copy** the completed transcript into the application you want.

</Steps>

Stored-audio transcription never inserts automatically because no destination
was captured at recording start.

## Generate speech

Text to speech is optional and off by default. It needs a speech synthesis
connection, not a microphone, recording shortcut, or STT setup.

<Steps>

1. **Open Text to speech** and add or select its connection as above.
2. **Open Model and voice settings**. Choose the model and voice ID, turn on
   **Enable text to speech**, and choose **Save settings**.
3. **Enter your text**, then choose **Speak** to generate and play audio.
4. **Use the playback controls** to pause, resume, restart, stop, or explicitly
   **Save generated speech** to a file.

</Steps>

You can also use **Listen** on retained completed transcripts. Freehand does not
automatically read transcripts aloud. See [Text to speech](../guides/using-freehand/#text-to-speech)
for playback and text lifetimes.

## Optional features

Local voice activity detection and the native status overlay are **on by
default**. You can configure or disable either. Voice detection alone does not
enable automatic stop, silence trimming, or checkpoints.

| Feature | Initial setting |
| --- | --- |
| Local voice detection and status overlay | On |
| Silence trimming, automatic stop, and pause-aware checkpoints | Off |
| Transcript cleanup and memory-only history | Off |
| Stored-audio response | Completed JSON; compatible streaming is selectable |
| Text-to-speech playback and Windows Mica material | Off |
| Direct insertion into the checked original target | On |
| Automatic update checks | On; configurable under **Settings → General** |
