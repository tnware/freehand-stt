Freehand bundles provider icons locally in the app and website. Brand marks
identify providers; they do not imply endorsement or certify model support.

| Where you see it | Identity treatment |
| --- | --- |
| Generic | Neutral protocol symbol |
| Speaches, whisper.cpp, Kokoro-FastAPI, openedai-speech | Freehand's neutral symbols |
| vLLM-Omni | vLLM family mark |
| NeMo-Speech.cpp | NVIDIA family mark from the licensed Lobe Icons collection |
| Model profiles | Qwen, NVIDIA, Cohere, and Mistral family marks |
| S1-mini | Neutral **S1** initials |

Local runtime headings, task shortcuts, and built-in Connections share these
icons with directory cards and guides.

:::note[Runtime and model identity]
A runtime's mark identifies the software serving the model. For example,
llama.cpp's mark does not identify Superwhisper or S1-mini.
:::
