Freehand bundles provider icons locally in the app and website. Brand marks
identify providers; they do not imply endorsement or certify model support.
Generic uses a neutral protocol symbol. Speaches, whisper.cpp, Kokoro-FastAPI,
and openedai-speech currently use Freehand's neutral symbols rather than an
official logo. vLLM-Omni shares the vLLM family mark. NeMo-Speech.cpp uses the
NVIDIA family mark, vendored from the same licensed Lobe Icons collection.
Model profiles use the Qwen, NVIDIA, Cohere, and Mistral family marks. S1-mini
uses neutral **S1** initials rather than an official Superwhisper logo. Directory
cards and individual guides share the same icons. Vendored brand assets use the
pinned sources and licenses listed below.
